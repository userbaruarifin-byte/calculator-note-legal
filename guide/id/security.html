Keamanan & backup

Semua pengaturan ini ada di Security. Buka brankas, lalu ketuk ikon perisai di kanan atas. Ikon perisai hanya muncul kalau brankas dibuka dengan password yang benar.

1. Sidik jari / wajah

Unlocking → Biometric unlock. Setelah dinyalakan, ketuk judul tiga kali lalu tempelkan jari. Tidak perlu mengetik password.

  • Sidik jari selalu membuka brankas yang asli.
  • Kalau sedang dipaksa membuka, abaikan sidik jari, ketik password lain, dan yang terbuka adalah brankas kosong (lihat Kalau password salah).
  • Sidik jari harus sudah didaftarkan di pengaturan HP terlebih dahulu.

2. Saat brankas terbuka

  • Lock when I leave the app (aktif sejak awal): brankas terkunci begitu kamu pindah ke aplikasi lain atau menekan Home. Memilih file atau membuka file di aplikasi lain tidak mengunci brankas.
  • Block screenshots (aktif sejak awal): layar brankas tidak bisa di-screenshot atau direkam, dan tampil hitam di daftar aplikasi terbaru.

3. Foto penyusup

If someone else tries → Photograph failed attempts (mati sejak awal). Setelah 3 kali password salah berturut-turut, kamera depan diam-diam memotret. Fotonya dan catatan percobaannya bisa dilihat di Security log.

  • Izin kamera baru diminta saat fitur ini kamu nyalakan.
  • Orang yang salah memasukkan password tidak diberi tahu bahwa dia dipotret.

4. Menyamarkan aplikasi

Disguise → App icon and name. Pilih Calculator, Weather, Clock, atau Compass.

  • Ikon dan nama di layar HP ikut berubah, termasuk di menu Share aplikasi lain.
  • Aplikasinya terbuka sebagai Weather (ketik nama kota), Clock (dengan stopwatch), atau Compass yang benar-benar berfungsi.
  • Cara masuk brankas: ketuk judul di atas layar Weather/Clock/Compass tiga kali dengan cepat, sama seperti di kalkulator.
Ikon hilang dari layar utama?Beberapa launcher menghapus ikon lama saat samaran diganti. Cari aplikasinya di laci aplikasi (app drawer), lalu tambahkan lagi ke layar utama. Nama di Pengaturan → Aplikasi tetap "Calculator".

5. Panic exit

Under pressure → Panic exit (mati sejak awal). Saat brankas terbuka:

  • telungkupkan HP di meja, atau
  • goyangkan HP dengan kuat beberapa kali,

maka brankas langsung terkunci dan kembali ke kalkulator.

PerhatikanMemegang HP di atas wajah sambil berbaring bisa terbaca sebagai "telungkup". Coba dulu fitur ini sebelum kamu benar-benar mengandalkannya.

6. Backup & pindah HP

Isi brankas hanya ada di HP ini. Isinya tidak ikut backup otomatis Google. Kalau HP hilang, rusak, atau diganti tanpa backup, isinya ikut hilang.

Membuat backup

  1. Backup → Back up to a file.
  2. Buat Backup password, lalu ketik sekali lagi di Type it again. Password ini boleh berbeda dari password brankas. Jangan sampai lupa.
  3. Pilih tempat menyimpan file backup, misalnya Google Drive atau folder Download, lalu ketuk Back up.

File backup berisi catatan (beserta gambarnya), file tersembunyi, Shared Content dan link, rumus buatanmu, Cash Log, dan pengingat. Semuanya terenkripsi dengan password backup.

Memulihkan di HP baru

  1. Pasang aplikasinya, lalu buat password brankas.
  2. Buka Security → Backup → Restore from a backup.
  3. Pilih file backup, lalu masukkan password backup.
Aman diulangRestore hanya menambahkan isi backup dan tidak pernah menimpa yang sudah ada. Restore file yang sama dua kali tidak membuat isinya dobel.

7. Mengganti password

Buka Encrypted Note, buka menu samping, lalu pilih Change password. Kamu perlu memasukkan password lama. Menu ini hanya muncul kalau brankas dibuka dengan password yang benar.
